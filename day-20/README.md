# Day 20: Milestone — Contact Book (mini-project)

**Module:** 2 — Data Structures & Files

## What you're building

A command-line **contact book**: add, list, search, and delete contacts, with
everything saved to a text file so your contacts are still there next time you
run the program. This pulls together every tool from this module: lists, dicts,
string methods, and file I/O with `with`.

Full instructions, code, and a stretch goal live in [`project/`](project/) —
start there.

## What this exercises

- **Dicts** ([Day 13](../day-13/README.md)) — each contact is a dict with name,
  phone, and email.
- **Lists** ([Day 11](../day-11/README.md)) — all contacts are held in a list.
- **String methods** ([Day 16](../day-16/README.md)) — parsing and formatting
  contact data.
- **File handling** ([Days 17-18](../day-17/README.md)) — loading and saving
  contacts to `contacts.txt` with `with`.
- **Functions** ([Day 8](../day-08/README.md)) and **control flow**
  ([Day 6](../day-06/README.md)-[7](../day-07/README.md)) — the menu loop and
  each command.

## Run it

```bash
python day-20/project/contact_book.py
```

See [`project/README.md`](project/README.md) for the full write-up, sample
session, and the stretch goal.
